Work 02:

MEDAL CASE

러닝 메달케이스

완주 메달은 대부분 서랍에 들어갑니다. 달린 코스의 지형을 메달 아래에 깔고, 이름과 기록을 새긴 케이스를 만들었습니다. 한 사람의 레이스마다 한 개씩 주문받아 출력합니다.

형태
육각 케이스 · 사각 케이스
제작
3D 프린팅 (FDM), 주문 제작
입력
레이스 GPX 기록
구성
코스 지형 맵 · 원형 메달 자리 · 자석 뚜껑 · 명판 2장
명판
대회명 · 이름 / BIB / 기록 (59 × 20 mm)
생성기
주문서 → 출력용 3D 파일 자동 생성 (자체 개발)
판매
HEXATRAIL 브랜드 (와디즈 펀딩)
01 — DATA

기록을 지형으로

러너가 보낸 GPX 기록으로 코스 주변 지형을 입체 맵으로 만들고, 달린 길을 색으로 올립니다.

02 — STRUCTURE

메달을 담는 구조

지형 맵 위에 메달이 앉는 원형 자리를 두고, 메달 지름과 두께에 맞춰 만듭니다. 뚜껑은 자석으로 닫히고, 육각 뚜껑판에는 로고나 문구를 올립니다.

03 — PERSONAL

한 사람의 기록

명판 두 장에 대회명과 이름, 배번, 기록을 돋을새김으로 넣습니다. 기록 줄은 강조색으로 따로 출력합니다.

04 — SYSTEM

주문에서 출력까지

자체 개발 · 자동 생성기

주문서에 적힌 케이스, 문구, 색을 읽어 출력용 3D 파일과 작업 지시서를 자동으로 만드는 생성기를 직접 개발했습니다. 명판 글자는 줄 수와 글자 수에 맞춰 크기를 스스로 맞춥니다. 영상은 한 글자 입력할 때마다 이 생성기로 만든 실제 명판입니다.

  • 주문서 한 장 → 케이스 · 명판 출력 파일
  • 지형 맵과 부품별 필라멘트 색 지정
  • 출력 시간 · 필라멘트 무게를 적은 작업 지시서

고객이 직접 고르는 주문 화면은 개발 중입니다.
